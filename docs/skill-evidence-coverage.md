# Skill evidence coverage

This map shows where each skill gets its supporting evidence. It is not a bug list. Use it to decide whether a skill has reproduced OSS cases, candidate leads, primary-source references, or only routing examples.

## Evidence levels

- **Validated casebook:** `docs/oss-validation-cases.md` has source-line evidence, user-visible failure mode, patch shape, and confidence.
- **Candidate backlog:** `docs/oss-maintainer-candidate-backlog.md` has maintainer-plausible leads. Re-check the current default branch and reproduce locally before filing.
- **Primary-source reference:** the skill or its `references/*.md` files cite official docs, specs, browser bugs, library docs, or prior art.
- **Routing only:** the document helps choose a skill but does not claim external defect evidence.

## Update rule

When adding a skill, add at least one row here before promoting it in README. The row can say `Routing only` or `Candidate backlog only`; do not invent validation cases to make coverage look complete.
